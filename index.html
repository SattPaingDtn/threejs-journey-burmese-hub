🎥 ကင်မရာ အမျိုးအစား (Camera Type)

PerspectiveCamera: လူ့မျက်လုံးလို အနီးရှိအရာများ ကြီးမားပြီး အဝေးရှိအရာများ သေးငယ်သွားသော Frustum Projection ဖြစ်သည်။

⚙️ Perspective Parameters

🕹️ Control Mode နှင့် Motion Math

OrbitControls: Target ဗဟိုပြု လှည့်ပတ်ခြင်း (Orbit, Pan, Zoom)။ Damping သုံးပါက tick() ထဲတွင် controls.update() ခေါ်ပေးရမည်။

💻 Live Generated Code

// Perspective Camera const camera = new THREE.PerspectiveCamera(75, sizes.width / sizes.height, 0.1, 100) camera.position.set(0, 1.5, 4) scene.add(camera)
