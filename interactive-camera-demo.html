🎥 ကင်မရာ အမျိုးအစား (Camera Type)

PerspectiveCamera: လူ့မျက်လုံးလို အနီးရှိအရာများ ကြီးမားပြီး အဝေးရှိအရာများ သေးငယ်သွားသော Frustum Projection ဖြစ်သည်။

⚙️ Perspective Camera Parameters

15° (Telephoto/Zoom) $\leftrightarrow$ 120° (Wide-angle/Fisheye)

🕹️ Control Mode နှင့် Motion Math

OrbitControls: Target ဗဟိုပြု လှည့်ပတ်ခြင်း (Orbit, Pan, Zoom)။ Damping ဖွင့်ထားပါက tick() ထဲတွင် controls.update() မဖြစ်မနေ ခေါ်ရပါမည်။

💻 Live Generated Code

const camera = new THREE.PerspectiveCamera(75, sizes.width / sizes.height, 0.1, 100) camera.position.set(0, 1.5, 4) scene.add(camera)

🧠 Deep-Dive အရေးကြီး သဘောတရားများ

  • Matrix Pipeline: Local $\to$ World $\to$ View (Camera Inverse) $\to$ Clip (Frustum) $\to$ Screen
  • Z-Fighting Math: Depth buffer သည် Non-linear ($1/Z$) ဖြစ်၍ near နားတွင်သာ Precision စုပြုံနေသည်။ 0.0001 နှင့် 999999 ကဲ့သို့ အစွန်းတရားများ မသုံးရပါ။
  • Orthographic Aspect Ratio: Left/Right ကို aspectRatio ဖြင့် မမြှောက်ပါက ပုံပျက်သွားပါမည်။
  • LookAt Math: (0, 10, 0) မှ (0, 0, 0) ဒေါင်လိုက်တည့်တည့် ကြည့်လျှင် Gimbal Lock မဖြစ်စေရန် camera.up.set(0, 0, -1) ပြောင်းပေးပါ။
