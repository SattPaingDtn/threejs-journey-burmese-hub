## ၁။ Three.js Journey မှ ကြိုဆိုပါတယ်

Three.js နဲ့ 3D website တစ်ခု ဖန်တီးတတ်ဖို့ဆိုတာ library ရဲ့ command တွေကို မှတ်ထားရုံနဲ့ မလုံလောက်ပါဘူး။ Scene တည်ဆောက်ပုံ၊ camera၊ geometry၊ material၊ lighting၊ animation နဲ့ performance စတဲ့ အကြောင်းအရာတွေ တစ်ခုနဲ့တစ်ခု ဆက်စပ်နေပါတယ်။

ဒါကြောင့် ဒီ course က အခြေခံကနေ စပြီး တစ်ဆင့်ချင်း တည်ဆောက်သွားတဲ့ ပုံစံဖြစ်ပါတယ်။ လက်ရှိမှာ WebGL နဲ့ Three.js အကြောင်း လုံးဝမသိသေးရင်တောင် စတင်လို့ရပါတယ်။ အရေးကြီးတာက **အလျင်မလိုဘဲ ကိုယ်တိုင်စမ်းရေးဖို့** ပါပဲ။

> **မှတ်ထားရန်** — ဒီနေ့ရဲ့ ရည်မှန်းချက်က Three.js ကို ကျွမ်းကျင်သွားဖို့ မဟုတ်ပါဘူး။ ကိုယ်သွားမယ့်လမ်းကို မြင်ပြီး ပထမဆုံးခြေလှမ်း စလှမ်းဖို့ပါ။

## ၃။ ဘာကြောင့် အစဉ်လိုက် လေ့လာသင့်တာလဲ

Three.js ဟာ ကျယ်ပြန့်ပါတယ်။ React Three Fiber၊ shader သို့မဟုတ် physics လို စိတ်ဝင်စားစရာ topic ဆီ တန်းသွားချင်တာ သဘာဝပါပဲ။ ဒါပေမယ့် အဆင့်မြင့်အပိုင်းတွေမှာ scene၊ transform၊ camera၊ material နဲ့ animation အခြေခံတွေကို အကြိမ်ကြိမ် ပြန်အသုံးပြုရပါတယ်။

အကောင်းဆုံးနည်းက lesson တွေကို အစဉ်လိုက် လေ့လာခြင်းပါ။ ကိုယ်သိပြီးသား topic ဆိုရင် မြန်မြန်ပြန်ကြည့်နိုင်ပေမယ့် မသေချာသေးတဲ့အပိုင်းကို မကျော်သင့်ပါဘူး။ အဆင့်မြင့် lesson တစ်ခုမှာ ခက်နေပြီဆိုရင် ကိုယ်မတည်ငြိမ်သေးတဲ့ အခြေခံ lesson ဆီ ပြန်သွားတာဟာ နောက်ကျသွားခြင်းမဟုတ်ဘဲ ပိုမြန်မြန်တိုးတက်ဖို့ လုပ်တာပါ။

## ၄။ Course လမ်းပြမြေပုံ

Course ကို ခရီးရှည်တစ်ခုလို မြင်ကြည့်ပါ။ Chapter တစ်ခုစီက နောက် chapter အတွက် လိုအပ်တဲ့စွမ်းရည်ကို တည်ဆောက်ပေးပါတယ်။

### Chapter 1 — Basics

ပထမဆုံး scene တည်ဆောက်ခြင်း၊ object ထည့်ခြင်း၊ transform လုပ်ခြင်း၊ camera နဲ့ render လုပ်ခြင်း၊ texture၊ material နဲ့ animation အသုံးပြုခြင်းတို့ကို လေ့လာမယ်။ 3D project တစ်ခုရဲ့ အခြေခံအစိတ်အပိုင်းတွေကို ဒီ chapter မှာ ခိုင်မာအောင်လုပ်ရပါမယ်။

### Chapter 2 — Classic techniques

Lights၊ shadows၊ particles နဲ့ 3D object များကို interaction လုပ်ခြင်းလို အသုံးများတဲ့နည်းစနစ်တွေကို လက်တွေ့ project များနဲ့ လေ့လာမယ်။ ဒီနေရာကစပြီး ဖန်တီးမှုတွေ ပိုပြီး အသက်ဝင်လာမယ်။

### Chapter 3 — Advanced techniques

Imported models၊ physics၊ raycasting၊ realistic rendering နဲ့ project ကြီးတွေမှာ code စနစ်တကျ ဖွဲ့စည်းပုံတို့ကို လေ့လာမယ်။ Blender နဲ့ ကိုယ်ပိုင် 3D model ဖန်တီးခြင်းလည်း ပါဝင်ပါတယ်။

### Chapter 4 — Shaders

GPU ပေါ်မှာ အလုပ်လုပ်တဲ့ shader များကို လေ့လာပြီး ပုံမှန် material နဲ့ မရနိုင်တဲ့ visual effects တွေ ဖန်တီးမယ်။ အစပိုင်းမှာ ခက်နိုင်ပေမယ့် လေ့ကျင့်မှုနဲ့ တဖြည်းဖြည်း နားလည်လာနိုင်ပါတယ်။

### Chapter 5 — Extra techniques

Post-processing၊ performance optimization နဲ့ HTML/CSS ကို WebGL scene နဲ့ ပေါင်းစပ်နည်းတို့ကို လေ့လာမယ်။ လှပရုံတင်မကဘဲ အသုံးပြုသူရဲ့စက်ပေါ်မှာ ချောမွေ့စွာ အလုပ်လုပ်နိုင်ဖို့ပါ စဉ်းစားလာရမယ်။

### Chapter 6 — Portal scene

သင်ခဲ့သမျှနည်းစနစ်တွေကို ပေါင်းစပ်ပြီး Blender မှာ scene ပြင်ဆင်ခြင်းကနေ browser ပေါ်တင်ခြင်းအထိ project တစ်ခုလုံးကို အဆင့်လိုက် တည်ဆောက်မယ်။

### Chapter 7 — React Three Fiber

Three.js ကို React application ထဲမှာ React Three Fiber နဲ့ အသုံးပြုနည်းကို လေ့လာမယ်။ React မသိသေးသူအတွက် React အခြေခံသင်ခန်းစာလည်း ပါဝင်ပြီး နောက်ဆုံးမှာ interaction၊ physics နဲ့ UI ပါတဲ့ game project အထိ တည်ဆောက်မယ်။

> Chapter အမည်နဲ့ lesson အရေအတွက်တွေဟာ course update များအလိုက် ပြောင်းလဲနိုင်ပါတယ်။ လက်ရှိအစီအစဉ်ကို မူရင်း Three.js Journey website မှာ စစ်ဆေးပါ။

## ၅။ Course update တွေအကြောင်း

Web development နယ်ပယ်က အမြဲပြောင်းလဲနေပါတယ်။ Three.js၊ browser နဲ့ build tools တွေ update ဖြစ်လာတာနဲ့အမျှ အသုံးပြုပုံတွေ ပြောင်းနိုင်ပါတယ်။ Three.js Journey ရဲ့ အားသာချက်တစ်ခုက course content နဲ့ dependencies တွေကို ဆက်လက်ပြင်ဆင်ပေးနေခြင်း ဖြစ်ပါတယ်။

ဒါပေမယ့် code တစ်ကြောင်း အလုပ်မလုပ်တော့တဲ့အခါ ကိုယ်မှားတယ်လို့ ချက်ချင်းမယူဆပါနဲ့။

- မူရင်း lesson ရဲ့ starter files နဲ့ နှိုင်းယှဉ်ပါ။
- Browser console ထဲက error message ကို အရင်ဖတ်ပါ။
- လက်ရှိ Three.js documentation ကို ပြန်ကြည့်ပါ။

Version မတူခြင်းကြောင့် ဖြစ်တဲ့ပြဿနာနဲ့ ကိုယ့် code logic ကြောင့် ဖြစ်တဲ့ပြဿနာကို ခွဲခြားတတ်လာတာလည်း developer skill တစ်ခုပါပဲ။

## ၈။ Exercise နဲ့ code ကို ကိုယ်တိုင်ပိုင်အောင်လုပ်ခြင်း

Lesson အများစုမှာ စတင်ရေးသားဖို့ starter files နဲ့ ရလဒ်စစ်ဆေးဖို့ final files ရှိပါတယ်။ Final files ကို အဖြေကူးဖို့ထက် ကိုယ်ရေးထားတာနဲ့ ကွာခြားချက် စစ်ဖို့ သုံးတာ ပိုကောင်းပါတယ်။

Code style က developer တစ်ယောက်နဲ့တစ်ယောက် မတူနိုင်ပါတယ်။ ဆရာရေးတဲ့ပုံစံကို အရင်လိုက်ရေးပြီး နားလည်သွားတဲ့အခါ ကိုယ်ကြိုက်တဲ့ naming၊ formatting နဲ့ folder structure သို့ ပြန်ပြင်နိုင်ပါတယ်။ ရလဒ်မှန်ရုံနဲ့ မပြီးဘဲ **ဘာကြောင့် အလုပ်လုပ်တယ်** ဆိုတာ ရှင်းပြနိုင်ဖို့ ရည်ရွယ်ပါ။

Exercise တစ်ခုပြီးတိုင်း ဒီလိုထပ်စမ်းပါ။

1. Number သို့မဟုတ် color တန်ဖိုးတစ်ခု ပြောင်းကြည့်ပါ။
2. Object တစ်ခု ထပ်ထည့် သို့မဟုတ် ဖယ်ကြည့်ပါ။
3. Error တစ်ခုကို ရည်ရွယ်ပြီး ဖန်တီးကာ console message ကို ဖတ်ကြည့်ပါ။
4. Lesson မှာ မပါတဲ့ ကိုယ်ပိုင် idea သေးသေးလေးတစ်ခု ထည့်ပါ။

## ၉။ စတင်ရန် လိုအပ်ချက်များ

Three.js အတွေ့အကြုံ မလိုပါဘူး။ 3D သင်္ချာ ကျွမ်းကျင်ဖို့လည်း မလိုပါဘူး။ လိုအပ်တဲ့ formula တွေကို သက်ဆိုင်ရာ lesson ရောက်တဲ့အခါ လေ့လာနိုင်ပါတယ်။

ဒါပေမယ့် အောက်ပါအရာတွေ ရှိထားသင့်ပါတယ်။

- Software ထည့်သွင်းပြီး code ရေးနိုင်တဲ့ computer တစ်လုံး
- Variables၊ arrays၊ objects၊ loops၊ functions နဲ့ events စတဲ့ JavaScript အခြေခံ
- Code editor တစ်ခု — course မှာ Visual Studio Code ကို အသုံးပြုတယ်
- Developer tools ကောင်းကောင်းပါတဲ့ ခေတ်မီ browser တစ်ခု — မူရင်း course demonstrations များမှာ Chrome ကို အသုံးပြုတယ်
- စမ်းကြည့်လိုစိတ်နဲ့ မမှန်တာကို ပြန်ပြင်ဖို့ စိတ်ရှည်မှု

နောက်ပိုင်း chapter မှာ အခမဲ့ 3D software ဖြစ်တဲ့ Blender ကိုလည်း အသုံးပြုမယ်။ အခုချက်ချင်း Blender ကျွမ်းကျင်ထားစရာ မလိုပါဘူး။

### JavaScript အခြေခံ စစ်ဆေးရန်

အောက်က code ကို ဖတ်ပြီး ဘာထွက်မလဲ အကြမ်းဖျင်းရှင်းပြနိုင်ရင် စတင်ဖို့ လုံလောက်ပါတယ်။

```js
const topics = ['scene', 'camera', 'renderer']

topics.forEach((topic, index) => {
    console.log(`${index + 1}. ${topic}`)
})
```

မရှင်းသေးရင် JavaScript အခြေခံကို အရင်အနည်းငယ် ပြန်လေ့လာပြီးမှ Lesson 02 သို့ ဆက်သွားတာ ပိုအဆင်ပြေပါမယ်။

## ၁၀။ နားမလည်ဘဲ ပိတ်မိနေတဲ့အခါ

Error တွေ့တာဟာ programming လေ့လာခြင်းရဲ့ ပုံမှန်အစိတ်အပိုင်းပါ။ ချက်ချင်း code အကုန်ဖျက်ပြီး ပြန်စမယ့်အစား အောက်ပါအစီအစဉ်အတိုင်း စစ်ပါ။

1. **Console error ကို အစအဆုံးဖတ်ပါ။** File name နဲ့ line number ကို သတိထားပါ။
2. **မကြာခင်က ပြောင်းခဲ့တဲ့ code ကို စစ်ပါ။** စာလုံးပေါင်း၊ bracket နဲ့ import path တွေကို အရင်ကြည့်ပါ။
3. **Lesson ရဲ့ starter/final version နဲ့ နှိုင်းယှဉ်ပါ။** တစ်ခါတည်း file အကုန်မနှိုင်းဘဲ ပြဿနာရှိတဲ့အပိုင်းကိုသာ စစ်ပါ။
4. **ပြဿနာကို သေးငယ်အောင် လျှော့ပါ။** မလိုတဲ့ code တွေကို ယာယီပိတ်ပြီး error ဖြစ်စေတဲ့ အနည်းဆုံးအပိုင်းကို ရှာပါ။
5. **ရှာဖွေမေးမြန်းပါ။** မေးခွန်းတင်တဲ့အခါ error message၊ screenshot၊ သက်ဆိုင်ရာ code နဲ့ ကိုယ်စမ်းပြီးသားနည်းတွေကို ထည့်ပါ။

Three.js Journey student ဖြစ်ရင် member Discord ထဲက lesson သက်ဆိုင်ရာ channel မှာ အကူအညီတောင်းနိုင်ပါတယ်။ ကိုယ်တိုင်ဖြေရှင်းနိုင်သွားတဲ့ ပြဿနာဆိုရင်လည်း solution ကို မျှဝေပေးပါ။ ရှင်းပြပေးရင်း ကိုယ်တိုင် ပိုနားလည်လာပါတယ်။

## ၁၁။ ကိုယ့်လက်ရာကို မျှဝေပါ

Project ကို တခြားသူတွေဆီ ပြသခြင်းက feedback ရဖို့နဲ့ ဆက်လက်ဖန်တီးချင်စိတ်ရှိဖို့ ကူညီပါတယ်။ Lesson အတိုင်း တိတိကျကျ လိုက်လုပ်ထားတဲ့ရလဒ်ပဲဖြစ်ဖြစ်၊ ကိုယ်ပိုင်စိတ်ကူးထပ်ထည့်ထားတာပဲဖြစ်ဖြစ် ပြီးဆုံးအောင်လုပ်ပြီး မျှဝေကြည့်ပါ။

မျှဝေတဲ့အခါ အောက်ပါအချက်တွေ ထည့်နိုင်ပါတယ်။

- ဘာကို ဖန်တီးထားသလဲ
- ဘယ် lesson က concept ကို အသုံးပြုထားသလဲ
- ဘယ်အပိုင်းမှာ အခက်ဆုံးဖြစ်ခဲ့သလဲ
- ဘာ feedback လိုချင်သလဲ

ကောင်းမွန်တဲ့ feedback ဆိုတာ “လှတယ်” လို့ပြောရုံမကဘဲ ပိုကောင်းအောင် ဘယ်နေရာပြင်နိုင်မလဲဆိုတာ မြင်အောင်ကူညီပေးတာပါ။

## ၁၂။ Quiz နှင့် certificate

မူရင်း Three.js Journey course မှာ lesson တစ်ခုပြီးတိုင်း ကိုယ်နားလည်မှုကို စစ်ဆေးနိုင်တဲ့ quiz များ ရှိပါတယ်။ Quiz အားလုံးအောင်မြင်ပြီး သတ်မှတ်ချက်များ ပြည့်မီပါက completion certificate ရရှိနိုင်ပါတယ်။ Quiz နဲ့ certificate အသုံးပြုခွင့်အတွက် Three.js Journey account လိုအပ်နိုင်ပါတယ်။

Certificate က ရည်မှန်းချက်တစ်ခု ဖြစ်နိုင်ပေမယ့် အဓိကရလဒ်က ကိုယ်တိုင်ဖန်တီးထားတဲ့ projects နဲ့ ပြဿနာဖြေရှင်းနိုင်တဲ့စွမ်းရည် ဖြစ်ပါတယ်။
