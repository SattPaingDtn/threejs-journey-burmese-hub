## 🎯 ဤသင်ခန်းစာ၏ အဓိက ရည်ရွယ်ချက်
3D Web Development လောကသို့ ဝင်ရောက်ရာတွင် သိရှိထားရမည့် အခြေခံ သဘောတရားများ (CPU vs GPU ၏ အလုပ်လုပ်ပုံ)၊ Three.js ကို မည်သည့်နေရာများတွင် အသုံးပြုကြသည်နှင့် သင်တန်း၏ လမ်းပြမြေပုံကို ရှင်းလင်းလွယ်ကူစွာ နားလည်စေရန် ဖြစ်ပါသည်။

---

## 💡 Mental Model: CPU နှင့် GPU ၏ ကွာခြားချက်

3D Graphics ရေးဆွဲရာတွင် ကျွန်ုပ်တို့၏ ကွန်ပျူတာတွင် ဦးနှောက် (၂) မျိုး ရှိသည်:

```
┌────────────────────────────────────────┐      ┌────────────────────────────────────────┐
│         🧠 CPU (Central Processing)    │      │         ⚡ GPU (Graphics Processing)   │
├────────────────────────────────────────┤      ├────────────────────────────────────────┤
│ • Core နည်းသည် (ဥပမာ 4 to 16 Cores)     │      │ • Core ထောင်သောင်းချီ ပါဝင်သည် (3,000+) │
│ • အလွန်ရှုပ်ထွေးသော Logic များကို တွက်သည် │      │ • ရိုးရှင်းသော သင်္ချာများကို တစ်ပြိုင်နက်တွက်│
│ • အလုပ်တစ်ခုပြီးမှ တစ်ခု လုပ်သည် (Serial)│      │ • အမှတ် သန်းပေါင်းများစွာ တစ်ပြိုင်နက်တွက်  │
└────────────────────────────────────────┘      └────────────────────────────────────────┘
```

> **မြင်သာသော ဥပမာ**:  
> လူအယောက် ၁,၀၀၀ ကို ရေတစ်ခွက်စီ တိုက်လိုပါက —  
> * **CPU ပုံစံ**: အပြေးမြန်သော လူ ၁ ယောက်တည်းက တစ်ယောက်ပြီးတစ်ယောက် အလှည့်ကျ သွားတိုက်ခြင်း။  
> * **GPU ပုံစံ**: ရေခွက်ကိုင်ထားသော လူ ၁,၀၀၀ က လူ ၁,၀၀၀ စလုံးထံ **တစ်ပြိုင်နက်တည်း (Parallel)** သွားတိုက်ခြင်း။

---

## 🔑 အဓိက သဘောတရား (၃) ခု

### ၁။ WebGL ဆိုတာ ဘာလဲ?
* Browser ၏ `<canvas>` tag ပေါ်တွင် **GPU စွမ်းအား** ဖြင့် 3D ရုပ်ပုံများကို အလွန်မြန်ဆန်စွာ ရေးဆွဲပေးသော Low-Level စနစ် ဖြစ်သည်။
* ရေးသားရ အလွန်ရှုပ်ထွေးပြီး မျဉ်းကွေးတစ်ခုဆွဲရန်ပင် ကုဒ်စာကြောင်းရေ ရာချီ ရေးရသည်။

### ၂။ Three.js က မည်သို့ ကူညီပေးသလဲ?
* WebGL ၏ ရှုပ်ထွေးမှုများကို ဖုံးကွယ်ပေးပြီး JavaScript ဖြင့် အလွယ်တကူ ရေးသားနိုင်အောင် ကြားခံ ပံ့ပိုးပေးသော **3D Library** ဖြစ်သည်။
* ၂၀၁၀ တွင် **Ricardo Cabello (Mr.doob)** စတင် ဖန်တီးခဲ့ပြီး ယနေ့တိုင် ကမ္ဘာ့အသုံးအများဆုံး စံသတ်မှတ်ချက် ဖြစ်သည်။

### ၃။ Creative Web Development တွင် မည်သည့်နေရာများ၌ သုံးသလဲ?
* 🚗 **3D Product Configurators**: ကား၊ ဖိနပ်၊ နာရီ၊ ဖုန်းများကို ဝယ်ယူသူက ၃၆၀ ဒီဂရီ လှည့်ကြည့်ပြီး အရောင်နှင့် ပုံစံ စိတ်ကြိုက် ပြောင်းလဲခြင်း (ဥပမာ - Apple, Porsche, Nike)။
* 🎮 **Web Games & Experiences**: Browser ပေါ်တွင် တိုက်ရိုက် ကစားနိုင်သော 3D Games များနှင့် Virtual Events များ။
* 🎨 **Interactive Storytelling & Portfolios**: Scroll ဆွဲလိုက်သည့်အခါ 3D အရာဝတ္ထုများ လှုပ်ရှားကာ ဇာတ်လမ်းပြောပြသော Portfolio ဝက်ဘ်ဆိုက်များ။
