## 👋 ကဲ... သရုပ်ဆောင်တွေကို စတူဒီယိုထဲ နေရာရွှေ့ကြရအောင်!

မင်္ဂလာပါ! အခု ကျွန်တော်တို့ ဖန်တီးထားတဲ့ 3D Objects တွေကို ဘယ်/ညာ၊ အထက်/အောက် နေရာရွှေ့တာ (`position`), အရွယ်အစား ချဲ့တာ/ချုံ့တာ (`scale`), လှည့်ပတ်တာ (`rotation`) တွေ လုပ်ဆောင်သွားပါမယ်။

Three.js မှာ အရာဝတ္ထုတွေကို ထိန်းချုပ်ဖို့ အဓိက Properties (၄) ခု ရှိတယ်:
1. **`position`** (နေရာ ရွှေ့ပြောင်းခြင်း)
2. **`scale`** (အရွယ်အစား အကြီး/အသေး ပြုလုပ်ခြင်း)
3. **`rotation`** (ဒီဂရီဖြင့် လှည့်ပတ်ခြင်း - Euler)
4. **`quaternion`** (သင်္ချာ 4D ဖြင့် လှည့်ပတ်ခြင်း)

## 🧭 3D ဝင်ရိုးများကို မျက်စိထဲ မြင်အောင် ကြည့်နည်း (AxesHelper)

3D Space ထဲမှာ ဘယ်ဟာက $X, Y, Z$ လဲဆိုတာ ရှင်းရှင်းလင်းလင်း သိနိုင်ဖို့ **`AxesHelper`** ကို Scene ထဲ ထည့်ကြည့်လိုက်ပါ:

```javascript
scene.add(new THREE.AxesHelper(2)) // 2 unit အရှည်ရှိတဲ့ ဝင်ရိုးမျဉ်းများ
```

```
           +Y (Green / အစိမ်းရောင် - အပေါ်ဘက် ကောင်းကင်)
            │
            │
            └────────── +X (Red / အနီရောင် - ညာဘက်)
           /
          /
        +Z (Blue / အပြာရောင် - ဖန်သားပြင်အပြင်ဘက် မိမိဆီသို့ ဦးတည်)
```

> 💡 **ဆရာ့ရဲ့ ဝင်ရိုးအရောင် မှတ်နည်း**:  
> * 🔴 **Red (အနီရောင်)** = **$X$ Axis** (ညာဘက်သို့ သွားသည်)  
> * 🟢 **Green (အစိမ်းရောင်)** = **$Y$ Axis** (အပေါ်ဘက်သို့ သွားသည်)  
> * 🔵 **Blue (အပြာရောင်)** = **$Z$ Axis** (မိမိဆီသို့ ထွက်လာသည်)

## 📍 ၁။ Position (နေရာရွှေ့ခြင်း)

`position` သည် $X, Y, Z$ တန်ဖိုး ၃ ခု ပါရှိတဲ့ `Vector3` ဖြစ်ပါတယ်:

```javascript
// တစ်ခုချင်းစီ ရွှေ့ခြင်း
mesh.position.x = 1     // ညာဘက်သို့ 1 unit
mesh.position.y = -0.5  // အောက်ဘက်သို့ 0.5 unit
mesh.position.z = 2     // မိမိဆီသို့ 2 unit

// သို့မဟုတ် တစ်ကြောင်းတည်းဖြင့် သတ်မှတ်ခြင်း
mesh.position.set(1, -0.5, 2)

// အသုံးဝင်သော Vector3 Methods များ:
mesh.position.length()                        // ဗဟိုမှတ် (0,0,0) မှ အကွာအဝေး
mesh.position.distanceTo(camera.position)     // ကင်မရာနှင့် အကွာအဝေး
mesh.position.normalize()                     // ဦးတည်ရာမပြောင်းဘဲ အလျားကို 1 သို့ လျှော့ချခြင်း
```

---

## 🔍 ၂။ Scale (အရွယ်အစား ချဲ့/ချုံ့ခြင်း)

`scale` ရဲ့ မူလတန်ဖိုးက `1` ဖြစ်ပြီး ဆတိုး ချဲ့ထွင်ခြင်း ဖြစ်ပါတယ်:

```javascript
mesh.scale.x = 2    // အကျယ်ကို ၂ ဆ ချဲ့ခြင်း
mesh.scale.y = 0.5  // အမြင့်ကို တစ်ဝက် ချုံ့ခြင်း
mesh.scale.z = 1
mesh.scale.set(2, 0.5, 1) // တစ်ကြောင်းတည်း သတ်မှတ်ခြင်း
```

---

## 🔄 ၃။ Rotation (လည်ပတ်ခြင်းနှင့် Radians စနစ်)

Three.js မှာ ဒီဂရီ ($^\circ$) အစား **Radians** သင်္ချာကို သုံးပါတယ်။ အရမ်း လွယ်ပါတယ် ဒီလိုလေး မှတ်ထားလိုက်ပါ:

* $180^\circ = \pi \approx 3.14159$ (`Math.PI`)
* $360^\circ = 2\pi \approx 6.28318$ (`Math.PI * 2`)
* $90^\circ = \frac{\pi}{2} \approx 1.57079$ (`Math.PI * 0.5`)

```javascript
// Y ဝင်ရိုးအတိုင်း 45 ဒီဂရီ လှည့်ခြင်း
mesh.rotation.y = Math.PI * 0.25

// 💡 Gimbal Lock ပြဿနာ ရှောင်ရန် ဝင်ရိုး အစဉ်အလိုက် ပြောင်းခြင်း
mesh.rotation.reorder('YXZ')

// 💡 lookAt(): သတ်မှတ်ထားတဲ့ နေရာကို တည့်တည့် မျက်နှာမူစေခြင်း
camera.lookAt(mesh.position)
```

## 📦 ၄။ Scene Graph နှင့် အုပ်စုဖွဲ့ခြင်း (`THREE.Group`)

စဉ်းစားကြည့်ပါ... ကားတစ်စီးမှာ ဘီး ၄ ဘီး၊ ကားကိုယ်ထည်၊ စတီယာရင်တွေ ပါဝင်တယ်။ ကားကို ရွှေ့ရင် အကုန် အတူတူ လိုက်ပါစေချင်တယ် မဟုတ်လား? အဲ့ဒီအခါ **`THREE.Group`** ကို သုံးရပါတယ်:

```javascript
// ၁။ Group တစ်ခု ဖန်တီးပြီး Scene ထဲ ထည့်မယ်
const carGroup = new THREE.Group()
scene.add(carGroup)

// ၂။ အစိတ်အပိုင်းတွေကို Group ထဲသို့ ထည့်မယ်
carGroup.add(cube1, cube2, cube3)

// ၃။ Group တစ်ခုလုံးကို ရွှေ့လိုက်တာနဲ့ အားလုံး အတူတူ လိုက်ပါသွားမယ်!
carGroup.position.y = 1
carGroup.scale.set(1.5, 1.5, 1.5)
carGroup.rotation.y = Math.PI * 0.25
```

> * **အရာဝတ္ထုဆီ တည့်တည့် ချိန်လိုလျှင်** = `camera.lookAt(mesh.position)`
